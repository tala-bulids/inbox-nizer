# AI Smart Inbox

AI Smart Inbox is an email classification project that uses DistilBERT to classify emails into multiple categories.

The project started as a machine learning model and is now being developed into a backend application using FastAPI.

## Features

- Multi-label email classification
- Fine-tuned DistilBERT model
- FastAPI backend
- Email classification API
- Request validation
- Error handling
- Automated API testing

## Categories

- Business
- Customer Support
- Events & Invitations
- Finance & Bills
- Job Application
- Newsletters
- Personal
- Promotions
- Reminders
- Travel & Bookings
